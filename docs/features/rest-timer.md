# Rest timer

Automatic rest is enabled initially and uses 90 seconds unless the routine exercise specifies an override. Settings can disable automatic rest or change its default. A newly checked set restarts rest; correcting a checked set does not. Manual rest always takes a duration entered in the workout. Durations are whole seconds from 1 to 86400.

The active workout stores the deadline, so remaining time is derived from the current clock after navigation, backgrounding, lock, or relaunch. An expired timer displays Finished. This slice does not schedule alerts.
